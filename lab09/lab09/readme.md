# Лабораторная работа №9

## Моделирование системы массового обслуживания (ПВЗ)

### Цель работы

Смоделировать работу пункта выдачи заказов с использованием пуассоновского потока клиентов и исследовать характеристики очереди и обслуживания.

---

# Используемая модель

В модели используется:

* пуассоновский поток поступления клиентов;
* один оператор обслуживания;
* очередь клиентов;
* случайное время обслуживания.

---

# Основные параметры

* ? — интенсивность потока клиентов;
* T — время моделирования;
* tср — среднее время обслуживания;
* N — число прогонов моделирования.

---

# Используемые формулы

## Интервал между клиентами

Интервалы между поступлениями имеют экспоненциальное распределение:

[
\Delta t = -\frac{\ln(U)}{\lambda}
]

где:

* (U) — случайное число от 0 до 1;
* (\lambda) — интенсивность потока.

---

## Время обслуживания

Время обслуживания также моделируется экспоненциальным распределением:

[
t_{service} = -t_{ср} \cdot \ln(U)
]

---

## Время ожидания клиента

[
t_{wait} = t_{start} - t_{arrival}
]

где:

* (t_{arrival}) — момент прихода клиента;
* (t_{start}) — начало обслуживания.

---

## Среднее значение

[
M(X) = \frac{1}{n}\sum X_i
]

---

## Дисперсия

[
D(X) = \frac{1}{n}\sum (X_i - M(X))^2
]

Программа отображает:

# Вывод

В ходе работы была реализована модель системы массового обслуживания с пуассоновским потоком заявок.
Эксперимент показал, что при увеличении интенсивности потока или времени обслуживания очередь начинает расти, а среднее время ожидания увеличивается.
Полученные распределения соответствуют поведению одноканальной системы обслуживания.
