# Марковская модель погоды

В данной работе реализовано моделирование погоды с помощью марковской модели. Состояния соответствуют различным типам погоды (ясно, переменная облачность, облачно, пасмурно и дождь), а переходы между ними задаются матрицей интенсивностей Q. Единицей модельного времени выбран один час, что позволяет более реалистично описывать изменение погодных условий.

Во время работы выполняется визуализация изменения погоды по часам, а после завершения рассчитывается статистика: количество попаданий в каждое состояние, эмпирическое распределение и его сравнение с теоретическим стационарным распределением. Результаты моделирования автоматически сохраняются в файлы формата CSV.

В ходе выполнения работы было показано, что при увеличении времени моделирования эмпирическое распределение постепенно приближается к стационарному распределению, что соответствует теоретическим свойствам марковских процессов.
